## 宿題

- 取り組んだレベル：発展
- やったこと：`app/ask.py` で Gemini API の応答に含まれる `usage_metadata` を参照し、入力トークン数（`prompt_token_count`）と出力トークン数（`candidates_token_count`）を表示する処理を追加した。使用量情報が応答にない場合は、その旨を表示するようにした。また、APIを実際に呼び出さないテストを追加し、入力・出力トークン数の表示と回答文の戻り値を確認した。応答時間の計測や複数モデル・質問の実測比較はまだ行っていない。
- 結果：`app.ask` は API 応答の使用量メタデータから入力・出力トークン数を表示できる。一方、応答時間の計測と複数モデル・質問での比較はまだ実施していないため、実測値は未記録。
- 気づき・疑問：トークン数は質問や回答の長さによって変わり、応答時間もモデルや混雑状況で変わると考えられる。無料枠の制限はモデルや利用状況によって異なるため、実測時には429エラーの有無と、公式のレート制限をあわせて確認したい。どのモデル・利用枠で、1分あたりのリクエスト数やトークン数が制限に達するのか疑問。
